DEPLOYMENT TARGETS:
  Frontend: Vercel CDN (static files from app/dist)
  API:      Vercel Serverless Functions (api/** files)
  Both:     Single Vercel project at https://tasks-crafter.vercel.app

KEY ENDPOINTS:
  GET  /api/tasks                           List tasks (paginated)
  POST /api/tasks                           Create task
  GET  /api/tasks/:id                       Fetch task
  PUT  /api/tasks/:id                       Update task
  PATCH /api/tasks/:id/complete             Mark completed
  DELETE /api/tasks/:id                     Delete task
  GET  /api/health                          Health check

DEVELOPMENT:
  npm run dev:app                         Start Vite (port 5173)
  npm run dev:backend                       Start Express (port 3001)
  vercel dev                                Simulate production locally

PRODUCTION:
  git push origin main
  → Vercel auto-deploys in ~2 minutes
  → Available at https://tasks-crafter.vercel.app
